## 🏆 World Cup 2026 Sweeper 🏆

An interactive, balanced team shuffler built to run World Cup 2026 randomiser.

[Live Demo](https://world-cup-26-jd.vercel.app/)

![Homepage screenshot](./public/homepage.png)

### ⚙️ Getting Started

#### 1. Installation

Clone the repository and install the dependencies:

```
git clone https://github.com/jordandavidson1990/world-cup-26
cd world-cup-sweeper
npm install
```

#### 2. Run Locally

Start the local development server:

```
npm run dev
```

Open your browser and go to http://localhost:3000 to see the app.

#### 3. Running Tests

Run the test suite to verify the distribution logic and text formatting:

```
npm test
```

### 🌐 Deployment

This app is configured for automatic deployment on Vercel. You can check out the live production build at: https://world-cup-26-jd.vercel.app/
